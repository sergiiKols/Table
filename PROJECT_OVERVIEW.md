# 📊 Обзор проекта - Система Управления Данными

## 🎯 Цель проекта

Создание полнофункциональной системы управления данными с современной трехслойной архитектурой, демонстрирующей лучшие практики разработки веб-приложений.

## 📦 Что включено в проект

### ✅ Backend (ASP.NET Core 6.0)
- ✅ RESTful API с полным набором CRUD операций
- ✅ Entity Framework Core для работы с БД
- ✅ Repository Pattern для абстракции данных
- ✅ DTO Pattern для валидации и безопасности
- ✅ Dependency Injection
- ✅ Swagger документация
- ✅ CORS настройка
- ✅ Обработка ошибок и логирование
- ✅ Seed данные для тестирования

### ✅ Frontend (React 18 + Vite)
- ✅ Современный React с хуками
- ✅ Компонентная архитектура
- ✅ React Bootstrap для UI
- ✅ Axios для HTTP запросов
- ✅ Управление состоянием
- ✅ Валидация форм
- ✅ Адаптивный дизайн
- ✅ Красивый UI с градиентами

### ✅ Database (MS SQL Server)
- ✅ Оптимизированная схема БД
- ✅ Индексы для производительности
- ✅ Миграции Entity Framework
- ✅ Seed данные

### ✅ Документация
- ✅ README.md - Полная документация
- ✅ QUICKSTART.md - Быстрый старт
- ✅ ARCHITECTURE.md - Описание архитектуры

### ✅ Утилиты

## 🎨 Основные функции

### 1. 📋 Просмотр данных
- Табличное отображение всех записей
- Сортировка по дате создания
- Форматирование дат и валют
- Индикаторы статуса (активен/неактивен)
- Категории с цветными бейджами

### 2. ➕ Добавление записей
- Модальное окно с формой
- Валидация полей на фронтенде
- Валидация на бэкенде
- Отображение ошибок валидации
- Автоматическое обновление таблицы

### 3. ✏️ Редактирование записей
- Двойной клик для быстрого редактирования
- Кнопка "Изменить" в строке таблицы
- Предзаполненная форма с данными
- Сохранение изменений с валидацией

### 4. 🗑️ Удаление записей
- Кнопка удаления в строке
- Подтверждение перед удалением
- Безопасное удаление из БД
- Обновление интерфейса

### 5. 🔍 Фильтрация и поиск
- Поиск по названию и описанию
- Фильтр по категории
- Фильтр по статусу (активен/неактивен)
- Комбинированные фильтры
- Кнопка сброса фильтров
