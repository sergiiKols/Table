## ❓ Проблемы?

### Backend не запускается?
- Проверьте: установлен ли .NET 6.0 SDK
- Команда: `dotnet --version`

### Frontend не запускается?
- Проверьте: установлен ли Node.js 18+
- Команда: `node --version`

### База данных не создается?
- Проверьте: запущен ли SQL Server
- Проверьте строку подключения в `appsettings.json`

### Подробнее в [QUICKSTART.md](QUICKSTART.md) → раздел "Решение проблем"
