# Frontend - React Application

## Обзор

Frontend приложения построен на React 18 с использованием Vite в качестве сборщика и dev-сервера.

## Структура проекта

```
Frontend/
├── src/
│   ├── components/           # React компоненты
│   │   ├── DataTable.jsx    # Таблица данных
│   │   ├── DataItemModal.jsx # Модальное окно редактирования
│   │   └── FilterBar.jsx    # Панель фильтрации
│   ├── services/             # API сервисы
│   │   └── dataService.js   # Сервис для работы с API
│   ├── App.jsx               # Главный компонент
│   ├── App.css               # Стили приложения
│   ├── main.jsx              # Точка входа
│   └── index.css             # Глобальные стили
├── index.html
├── package.json
├── vite.config.js
└── README.md
```

## Компоненты

### App.jsx
Главный компонент приложения, управляет состоянием и координирует взаимодействие компонентов.

**Основные функции:**
- Загрузка данных при монтировании
- Управление модальным окном
- Обработка CRUD операций
- Управление фильтрами

### DataTable.jsx
Компонент отображения данных в табличном виде.

**Возможности:**
- Отображение данных с форматированием
- Обработка двойного клика для редактирования
- Кнопки действий (редактировать, удалить)
- Индикация загрузки
- Пустое состояние

### DataItemModal.jsx
Модальное окно для создания и редактирования записей.

**Возможности:**
- Форма с валидацией
- Поддержка режимов создания/редактирования
- Отображение ошибок валидации
- Индикация сохранения

### FilterBar.jsx
Панель управления и фильтрации данных.

**Возможности:**
- Кнопки действий (добавить, обновить)
- Поиск по тексту
- Фильтр по категории
- Фильтр по статусу
- Сброс фильтров

## Сервисы

### dataService.js
HTTP клиент для работы с Backend API, использует Axios.

**Методы:**
- `getAll()` - получить все элементы
- `getById(id)` - получить элемент по ID
- `getFiltered(category, isActive, searchTerm)` - фильтрация
- `create(item)` - создать новый элемент
- `update(id, item)` - обновить элемент
- `delete(id)` - удалить элемент

## Установка и запуск

### Установка зависимостей

```bash
npm install
```

### Запуск в режиме разработки

```bash
npm run dev
```

Приложение будет доступно по адресу: `http://localhost:3000`

### Сборка для продакшена

```bash
npm run build
```

Результат будет в папке `dist/`

### Предпросмотр production сборки

```bash
npm run preview
```

## Конфигурация

### vite.config.js

```javascript
export default defineConfig({
  plugins: [react()],
  server: {
    port: 3000,
    open: true
  }
})
```

### API конфигурация

API URL настраивается в `src/services/dataService.js`:

```javascript
const API_BASE_URL = 'http://localhost:5000/api';
```

## Особенности реализации

### Управление состоянием
Используется useState для локального состояния компонентов.

### Асинхронные операции
Все API вызовы обернуты в try-catch с обработкой ошибок.

### Валидация форм
Клиентская валидация перед отправкой на сервер.

### Форматирование данных
- Даты: русская локаль с временем
- Суммы: российский рубль
- Статусы: цветные бейджи

## Примеры использования

### Добавление нового элемента

1. Нажмите кнопку "➕ Добавить"
2. Заполните форму
3. Нажмите "Сохранить"

### Редактирование элемента

**Способ 1:** Дважды кликните по строке
**Способ 2:** Нажмите "✏️ Изменить"

### Фильтрация данных

1. Введите поисковый запрос
2. Выберите категорию (опционально)
3. Выберите статус (опционально)
4. Нажмите "Применить"

## Troubleshooting

### Проблема: npm install не работает
**Решение:** Убедитесь, что установлен Node.js 18+

### Проблема: Порт 3000 занят
**Решение:** Измените порт в `vite.config.js`

### Проблема: CORS ошибки
**Решение:** Убедитесь, что Backend запущен и CORS настроен правильно

### Проблема: API запросы не работают
**Решение:** Проверьте API_BASE_URL в dataService.js
